#+title: Doom on iPad — Cheat Sheet
(Open anytime with =SPC ?=. Press =SPC= and wait: a menu shows every key.)

* Getting in / out
| Shell command  | Does                                             |
|----------------+--------------------------------------------------|
| =e file=       | open file in running Emacs (starts it if needed) |
| =e .=          | open current dir                                 |
| =ekill=        | stop the Emacs daemon                            |
| =doom sync=    | after editing init.el / packages.el              |

Inside Emacs: =SPC q q= closes this frame (Emacs keeps running, your
buffers stay open). Reconnect from iPad → =e= → everything is where you left it.

* Modes (vim)
| Key         | Does                                    |
|-------------+-----------------------------------------|
| =i= / =a=   | start typing (before / after cursor)    |
| =jk=        | back to normal mode (iPad has no Esc)   |
| =C-[=       | also Esc                                |
| =C-s=       | save (files also auto-save after 5s)    |
| =u= / =C-r= | undo / redo                             |
| =v= / =V=   | select chars / lines                    |

* Files & projects

|-------------+------------------------------|
| =SPC SPC=   | find file in project         |
| =SPC .=     | find file (browse)           |
| =SPC f r=   | recent files                 |
| =SPC ,=     | switch buffer                |
| =SPC p p=   | switch project               |
| =SPC o p=   | file tree (treemacs)         |
| =SPC o -=   | file manager (dired) here    |
| =SPC /=     | search text in project       |
| =SPC s s=   | search in this file          |
| =SPC `=     | flip to previous file        |
| =]b= / =[b= | next / prev open file        |

* Folder browser (dired, =SPC o -=)

|-------------+----------------------------------|

* Right sidebar: file tree + git panel (like VS Code)
File tree (=SPC o p=) on top, git panel (=SPC o g=) below it.
File tree: =j/k= move, =TAB= expand, =RET= open, =q= hide.
=SPC p p= switches project.

The git panel opens by itself when you open a file in a git repo on a
wide screen (150+ columns), follows you between repos, and refreshes
when files change on disk. =q= / =SPC o g= hides it (stays hidden until
=SPC o g= again).

| Key (in git panel) | Does                                   |
|--------------------+----------------------------------------|
| =RET=              | open file in the main area             |
| =TAB=              | show / hide the file's diff            |
| =s= / =u=          | stage / unstage                        |
| =x=                | discard change (asks first)            |
| =c c=              | commit staged (message opens main area) |
| =P p=              | push                                   |
| =q=                | hide panel                             |

* pi + live diff
Shell, inside any git repo: =pd= → pi on one side, live diff on the other
(side by side when wide, stacked when narrow). Tap a pane to switch.
Inside Emacs: =SPC g d= turns the current window into the live diff.

| Key (in diff)     | Does                                  |
|-------------------+---------------------------------------|
| =C-j= / =C-k=     | next / prev section (file, hunk)      |
| =]= / =[=         | next / prev file                      |
| =TAB=             | fold / unfold                         |
| =RET=             | jump to that line in the file         |
| =s= / =u=         | stage / unstage (file or hunk)        |
| =x=               | discard change (asks first)           |
| =c c=             | commit staged                         |
| =q=               | close                                 |

tmux: =C-b z= zooms the current pane full screen (again = back).
=C-b o= switches pane without touching the screen.

* iPad setup tips
- *Blink Shell* recommended (mosh, OSC 52 clipboard, key remaps).
  - Settings → Keyboard → map Caps Lock → Esc.
  - Settings → Keyboard → Option as Meta.
- Copying in Emacs (=y=) lands on the iPad clipboard via OSC 52.
- Touch / trackpad: tap to place cursor, two-finger scroll works.

* Language servers (optional, for LSP features)
Emacs works without them. Install any you want, then reopen the file:
| Language   | Install                                          |
|------------+--------------------------------------------------|
| Python     | =uv tool install ty= ; =uv tool install ruff=    |
| JS/TS      | =npm i -g typescript typescript-language-server= |
| Go         | =go install golang.org/x/tools/gopls@latest=     |
| Rust       | =rustup component add rust-analyzer=             |
| Bash       | =npm i -g bash-language-server=                  |
| YAML       | =npm i -g yaml-language-server=                  |
| HTML/CSS/JSON | =npm i -g vscode-langservers-extracted=       |
| Typst      | =tinymist= binary on PATH; grammar: =M-x treesit-install-language-grammar RET typst= |
| R          | R's =languageserver= package                     |
